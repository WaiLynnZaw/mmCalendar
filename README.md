# မြန်မာပြက္ခဒိန် ၁၀၀

React + Vite ဖြင့်ရေးထားသော မြန်မာ/ဂရီဂိုရီယန် နှစ် ၁၀၀ ပြက္ခဒိန် UI။

## စတင်အသုံးပြုရန်

```sh
npm install
npm run dev
```

ရက်ရာဇာ၊ ပြဿဒါးနှင့် နဂါးခေါင်း အချက်အလက်များကို အခြေခံရိုးရာပုံစံဖြင့်တွက်ထားသည်။ ရုံးပိတ်ရက်စာရင်းတွင် ၂၀၂၆ အတွက် ထုတ်ပြန်ချက်ကို ထည့်သွင်းထားပြီး၊ အခြားနှစ်များ၏ အစိုးရပိတ်ရက်များသည် နှစ်အလိုက် ကြေညာချက်အပေါ်မူတည်သည်။
